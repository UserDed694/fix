# fix — VPN-клиент VictoryCloud

fix — кроссплатформенный VPN-клиент VictoryCloud для Android, Windows, macOS и Linux.
Приложение подключается к серверам VictoryCloud по ссылке-подписке и работает на ядре
Clash.Meta. Сайт: <https://victorycloud.ru>, поддержка: <https://t.me/VictorySup_bot>.

Основано на FlClash (GPL-3.0): <https://github.com/chen08209/FlClash>.
